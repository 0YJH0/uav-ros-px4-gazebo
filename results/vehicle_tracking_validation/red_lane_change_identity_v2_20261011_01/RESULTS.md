# 回中后身份评估 v2：离线重评

日期：2026-10-11。

**本次只修改评估方式，没有重新飞行，没有改动感知、关联、飞控或 10 秒盲跟限制。身份子项重评通过，整体仍不通过。**

原试验：[red_lane_change_gui_20261011_01](../red_lane_change_gui_20261011_01/RESULTS.md)。原始报告、图像、日志和执行源码均保留，不覆盖、不改写历史结论。

## 为什么改评估

旧方法只要原车和其他车的投影框 IoU 大于 0.1，就将整帧标记为 `overlap_unscorable`，未进一步比较机载确认框属于哪辆车。回中后两车同车道前后行驶，持续触发此条件，231 帧全部不可评分。

新版 `exclusive_projection_v2` 保留原有匹配 IoU 至少 0.4、第一名领先至少 0.2 的要求，同时检查投影几何证据：

1. 胜出车辆超过一半的投影框面积必须不与其他车辆框重叠。
2. 机载确认框必须覆盖该车辆超过一半的独占区域。
3. 若确认框同时覆盖另一辆车至少一半的独占区域，仍按多车合并框拒评；完全包含且无区分证据的情况也拒评。
4. 无确认框记为 `unconfirmed`，与“有框但身份模糊”分开。
5. 投影重叠事件独立统计，不再依赖拒评标签。计划遮挡、缺失位姿、缺失冻结几何仍不计作正确证据。

独占面积扣除所有竞争框的并集，避免重复扣除。该多数支持条件也会拒绝只覆盖单车投影 40%–50% 的小框，因此并非只放宽原规则。车辆颜色和轨迹 ID 不参与真值标签判定。

## 回中后 231 帧

| 新判定 | 帧数 |
| --- | ---: |
| 原车，具有独占投影支持 | 55 |
| 无机载确认框 | 67 |
| 同时覆盖多辆车独占区域，拒评 | 108 |
| 第一与第二候选匹配差值不足，拒评 | 1 |

新旧机载确认框数量不变。之前仅跳过统一重叠拒评得到的 163 个优势匹配框不能全部算正确：其中 108 个仍有合并框歧义。新版只接受 55 个具有进一步区分证据的框。

回中后首次独立几何确认延迟为 **2.30 仿真秒**；这不是重新飞行测得的恢复性能，也不能与墙钟恢复耗时直接混用。新版全程可评分错车观测为 0，不代表所有不可评分帧均正确。
